Architecture Abstraction Layer

概述

这是知识库最重要的架构文件之一。本条目定义了如何在 Spring AI / LangChain4j / SDK 之上构建一个业务无关的 AI 能力抽象层（Port & Adapter），实现框架锁定保护、厂商锁定保护和可测试性。

为什么要抽象

问题场景

问题 1: 框架锁定
@Service

    @Autowired
    private ChatClient chatClient;  // 直接依赖 Spring AI

            .user("分析订单: " + order)

解决方案：Port & Adapter（六边形架构）

                     ┌───────────────────────────────┐
                     │       业务代码层               │
                     │   (OrderService, QAService)   │
                     └───────────────┬───────────────┘
                                     │ 依赖（注入）
                     ┌───────────────▼───────────────┐
                     │      Port 接口层 (核心)        │

                     │  EmbeddingModelPort          │

                  ┌──────────▼──┐  ┌─────▼──────────┐
                  │ Spring AI   │  │ SDK 适配器      │

1. ChatModelPort

java
package com.example.ai.port;

import reactor.core.publisher.Flux;
import java.util.List;
import java.util.Map;

/**
 * 聊天模型端口 — 核心接口
 * 所有 LLM 对话的能力抽象
 */
public interface ChatModelPort {

    /**
     * 同步聊天
     */
    ChatResponse chat(ChatRequest request);

    /**
     * 流式聊天
     */
    Flux<ChatChunk> chatStream(ChatRequest request);

    /**
     * 获取模型信息
     */
    ModelInfo getModelInfo();

    // ──── 数据模型 ────

    record ChatRequest(
        List<ChatMessage> messages,        // 对话消息
        String requestId,                  // 请求追踪ID
        Double temperature,                // 温度参数
        Integer maxTokens,                 // 最大输出token
        Double topP,                       // top-p采样
        List<String> stopSequences,        // 停止序列
        List<ToolDefinition> tools,        // 可用工具
        String toolChoice,                 // 工具选择策略: auto/none/required
        ResponseFormat responseFormat,     // 输出格式
        Map<String, Object> metadata       // 扩展元数据（如conversationId）
    ) {
        public static Builder builder() {
            return new Builder();
        }

        public static class Builder {
            private final List<ChatMessage> messages = new ArrayList<>();
            private String requestId = java.util.UUID.randomUUID().toString();
            private Double temperature = 0.7;
            private Integer maxTokens = 2048;
            private Double topP = 0.9;
            private List<String> stopSequences = List.of();
            private List<ToolDefinition> tools = List.of();
            private String toolChoice = "auto";
            private ResponseFormat responseFormat = ResponseFormat.TEXT;
            private Map<String, Object> metadata = Map.of();

            public Builder addSystemMessage(String content) {
                messages.add(new ChatMessage("system", content, null, null));
                return this;
            }

            public Builder addUserMessage(String content) {
                messages.add(new ChatMessage("user", content, null, null));
                return this;
            }

            public Builder addAssistantMessage(String content) {
                messages.add(new ChatMessage("assistant", content, null, null));
                return this;
            }

            public Builder addToolResult(String toolCallId, String content) {
                messages.add(new ChatMessage("tool", content, toolCallId, null));
                return this;
            }

            public Builder temperature(Double temperature) {
                this.temperature = temperature;
                return this;
            }

            public Builder maxTokens(Integer maxTokens) {
                this.maxTokens = maxTokens;
                return this;
            }

            public Builder tools(List<ToolDefinition> tools) {
                this.tools = tools;
                return this;
            }

            public Builder responseFormat(ResponseFormat format) {
                this.responseFormat = format;
                return this;
            }

            public ChatRequest build() {
                return new ChatRequest(
                    List.copyOf(messages), requestId, temperature,
                    maxTokens, topP, stopSequences, List.copyOf(tools),
                    toolChoice, responseFormat, Map.copyOf(metadata));
            }
        }
    }

    record ChatMessage(
        String role,          // system / user / assistant / tool
        String content,       // 文本内容
        String toolCallId,    // tool 消息的关联ID
        List<ToolCall> toolCalls  // assistant 消息的工具调用
    ) {}

    record ChatResponse(
        String content,              // 文本内容
        List<ToolCall> toolCalls,    // 工具调用列表
        String finishReason,         // stop / length / tool_calls
        TokenUsage tokenUsage,       // Token 使用统计
        String modelId,              // 实际使用的模型ID
        Map<String, Object> metadata // 额外元数据
    ) {}

    record ChatChunk(
        String delta,          // 增量文本
        String finishReason,   // 流结束时的原因
        TokenUsage tokenUsage  // 累积token使用（可能为null）
    ) {}

    record ToolDefinition(
        String name,
        String description,
        Map<String, Object> jsonSchema  // JSON Schema
    ) {}

    record ToolCall(
        String id,
        String name,
        String arguments  // JSON string
    ) {}

    record TokenUsage(
        int inputTokens,
        int outputTokens,
        int totalTokens
    ) {
        public static final TokenUsage EMPTY = new TokenUsage(0, 0, 0);

        public TokenUsage add(TokenUsage other) {
            return new TokenUsage(
                inputTokens + other.inputTokens,
                outputTokens + other.outputTokens,
                totalTokens + other.totalTokens);
        }
    }

    record ModelInfo(
        String modelId,
        String provider,
        int contextWindow,
        double inputPricePer1M,
        double outputPricePer1M,
        boolean supportsVision,
        boolean supportsToolCalling,
        boolean supportsStreaming
    ) {}

    enum ResponseFormat { TEXT, JSON_OBJECT, JSON_SCHEMA }
}

适配器实现示例

Spring AI ChatModel Adapter

java
package com.example.ai.adapter;

import com.example.ai.port.ChatModelPort;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.model.ChatModel;
import reactor.core.publisher.Flux;

/**
 * Spring AI ChatModel 适配器
 * 将 Spring AI 的 ChatClient 适配为 ChatModelPort
 */
@Component
@ConditionalOnBean(ChatModel.class)
public class SpringAiChatModelAdapter implements ChatModelPort {

    private final ChatClient chatClient;
    private final ChatModel chatModel;
    private final String modelId;

    public SpringAiChatModelAdapter(ChatClient.Builder builder,
            ChatModel chatModel,
            @Value("${app.ai.default-model:gpt-4o}") String modelId) {
        this.chatClient = builder.build();
        this.chatModel = chatModel;
        this.modelId = modelId;
    }

    @Override
    public ChatResponse chat(ChatRequest request) {
        var prompt = chatClient.prompt();

        // 添加消息
        for (var msg : request.messages()) {
            switch (msg.role()) {
                case "system" -> prompt.system(msg.content());
                case "user" -> prompt.user(msg.content());
                case "assistant" -> {
                    if (msg.toolCalls() != null) {
                        prompt.messages(
                            new org.springframework.ai.chat.messages
                                .AssistantMessage(msg.content()));
                    } else {
                        prompt.messages(
                            new org.springframework.ai.chat.messages
                                .AssistantMessage(msg.content()));
                    }
                }
            }
        }

        // 配置参数
        prompt.options(
            org.springframework.ai.chat.prompt.ChatOptionsBuilder.builder()
                .withTemperature(request.temperature())
                .withMaxTokens(request.maxTokens())
                .withTopP(request.topP())
                .build());

        // 执行
        var response = prompt.call().chatResponse();
        var output = response.getResult().getOutput();

        // 转换 Token 使用量
        var usage = new TokenUsage(0, 0, 0);
        if (response.getMetadata() != null && response.getMetadata().getUsage() != null) {
            var u = response.getMetadata().getUsage();
            usage = new TokenUsage(
                (int) u.getPromptTokens(),
                (int) u.getGenerationTokens(),
                (int) u.getTotalTokens());
        }

        // 转换工具调用
        var toolCalls = new ArrayList<ToolCall>();
        if (output instanceof AssistantMessage am && am.getToolCalls() != null) {
            for (var tc : am.getToolCalls()) {
                toolCalls.add(new ToolCall(tc.id(), tc.name(), tc.arguments()));
            }
        }

        return new ChatResponse(
            output.getContent(),
            toolCalls,
            response.getResult().getMetadata().getFinishReason(),
            usage,
            modelId,
            Map.of("framework", "spring-ai", "provider", "auto-detected"));
    }

    @Override
    public Flux<ChatChunk> chatStream(ChatRequest request) {
        var prompt = chatClient.prompt();

        for (var msg : request.messages()) {
            switch (msg.role()) {
                case "system" -> prompt.system(msg.content());
                case "user" -> prompt.user(msg.content());
            }
        }

        return prompt.stream().chatResponse()
            .map(chunk -> {
                var content = chunk.getResult().getOutput().getContent();
                var finishReason = chunk.getResult().getMetadata()
                    .getFinishReason();
                return new ChatChunk(content, finishReason, null);
            });
    }

    @Override
    public ModelInfo getModelInfo() {
        return new ModelInfo(
            modelId, "auto", 128000, 3.0, 15.0,
            true, true, true);
    }
}

OpenAI SDK 直接适配器（降级方案）

java
package com.example.ai.adapter;

import com.example.ai.port.ChatModelPort;
import com.openai.client.OpenAiClient;
import com.openai.client.okhttp.OpenAiOkHttpClient;
import com.openai.models.chat.completions.*;
import reactor.core.publisher.Flux;

/**
 * OpenAI SDK 直接适配器
 * 当 Spring AI 不支持某个 OpenAI 最新特性时使用
 */
@Component
@ConditionalOnProperty(name = "app.ai.adapter", havingValue = "openai-sdk")
public class OpenAiSdkChatModelAdapter implements ChatModelPort {

    private final OpenAiClient client;
    private final String modelId;

    public OpenAiSdkChatModelAdapter(
            @Value("${openai.api-key}") String apiKey,
            @Value("${openai.model:gpt-4o}") String modelId) {
        this.client = OpenAiOkHttpClient.builder()
            .apiKey(apiKey)
            .build();
        this.modelId = modelId;
    }

    @Override
    public ChatResponse chat(ChatRequest request) {
        var messages = convertMessages(request.messages());
        var tools = convertTools(request.tools());

        var params = ChatCompletionCreateParams.builder()
            .model(modelId)
            .messages(messages)
            .tools(tools)
            .temperature(request.temperature())
            .maxTokens(request.maxTokens())
            .build();

        var response = client.chat().completions().create(params);
        var choice = response.choices().get(0);

        // 转换 Token 使用量
        var usage = new TokenUsage(
            response.usage().map(CompletionUsage::promptTokens).orElse(0),
            response.usage().map(CompletionUsage::completionTokens).orElse(0),
            response.usage().map(CompletionUsage::totalTokens).orElse(0));

        // 转换工具调用
        var toolCalls = new ArrayList<ToolCall>();
        choice.message().toolCalls().ifPresent(tcs -> {
            for (var tc : tcs) {
                toolCalls.add(new ToolCall(
                    tc.id(), tc.function().name(), tc.function().arguments()));
            }
        });

        return new ChatResponse(
            choice.message().content().orElse(""),
            toolCalls,
            choice.finishReason() != null ?
                choice.finishReason().toString() : "stop",
            usage,
            modelId,
            Map.of("adapter", "openai-sdk-direct"));
    }

    @Override
    public Flux<ChatChunk> chatStream(ChatRequest request) {
        // 使用 OpenAI SDK 的流式 API
        return Flux.create(sink -> {
            var messages = convertMessages(request.messages());
            var params = ChatCompletionCreateParams.builder()
                .model(modelId)
                .messages(messages)
                .stream(true)
                .temperature(request.temperature())
                .maxTokens(request.maxTokens())
                .build();

            try (var stream = client.chat().completions().createStream(params)) {
                stream.forEach(chunk -> {
                    var choices = chunk.choices();
                    if (!choices.isEmpty()) {
                        var delta = choices.get(0).delta();
                        var content = delta.content().orElse("");
                        var finishReason = choices.get(0).finishReason();
                        sink.next(new ChatChunk(content,
                            finishReason != null ? finishReason.toString() : null, null));
                    }
                });
                sink.complete();
            } catch (Exception e) {
                sink.error(e);
            }
        });
    }

    @Override
    public ModelInfo getModelInfo() {
        return new ModelInfo(
            modelId, "openai", 128000, 3.0, 15.0,
            true, true, true);
    }

    private List<ChatCompletionMessageParam> convertMessages(
            List<ChatMessage> messages) {
        return messages.stream().map(msg -> switch (msg.role()) {
            case "system" -> ChatCompletionMessageParam.ofSystem(msg.content());
            case "user" -> ChatCompletionMessageParam.ofUser(msg.content());
            case "assistant" -> ChatCompletionMessageParam.ofAssistant(
                ChatCompletionAssistantMessageParam.builder()
                    .content(msg.content())
                    .build());
            default -> throw new IllegalArgumentException(
                "Unsupported role: " + msg.role());
        }).toList();
    }

    private List<ChatCompletionTool> convertTools(
            List<ToolDefinition> tools) {
        if (tools == null || tools.isEmpty()) return List.of();
        return tools.stream().map(t -> ChatCompletionTool.builder()
            .function(FunctionDefinition.builder()
                .name(t.name())
                .description(t.description())
                .parameters(SchemaDefinition.of(
                    com.openai.core.JsonObject.from(t.jsonSchema())))
                .build())
            .build()).toList();
    }
}

最佳实践

  1. 业务代码只依赖 Port 接口：通过构造函数注入，永远不 import Spring AI 或任何 SDK 的类
  2. Port 接口定义在独立的 Maven 模块：ai-port 模块零外部依赖，只有 JDK + Reactor（用于 Flux）
  3. Adapter 实现放在独立的 Maven 模块：ai-adapter-spring-ai, ai-adapter-openai-sdk 等，按需引入
  4. 使用 Spring @ConditionalOnBean/@ConditionalOnProperty 自动切换：部署时只需改配置，无需改代码
  5. 每个 Adapter 有完整的单元测试：用 WireMock 模拟 HTTP 响应，验证适配逻辑
  6. Port 接口设计遵循最小化原则：只暴露业务需要的操作，不暴露框架内部概念
  7. 将 Port 接口视为 API 合约：变更 Port 方法签名需要跨团队协调（因为影响了所有 Adapter 实现和所有消费者）

常见问题

Q: 这样是不是过度设计？

A: 如果你只用一个模型提供商且不打算换，可能是。但 AI 领域变化极快：(1) 模型价格战导致成本优化频繁，(2) 新模型/新协议不断出现，(3) 不同任务需要不同模型。Port & Adapter 的成本远低于"从头重写所有 AI 调用代码"。

Q: Port 接口如何处理不同 Provider 的特有特性（如 Anthropic cache_control）？

A: 两种方式：(1) 通过 metadata map 透传（灵活但不优雅），(2) 当特性足够通用时升级为 Port 方法的正式参数。经验法则：如果只有一个 Provider 支持的特性，走 metadata；如果两个以上 Provider 都支持，升级为正式参数。

Q: 适配层会有性能损失吗？

A: 几乎为零。适配层主要是对象转换（DTO → SDK 对象 → DTO），都是 in-memory 操作，相比网络 I/O（LLM API 调用通常 500ms-30s）完全可以忽略。
