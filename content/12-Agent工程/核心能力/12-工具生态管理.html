工具生态管理

概述

当Agent系统中工具数量从个位数增长到数十甚至上百个时，工具的管理成为一个独立的工程问题。工具需要被注册、发现、动态加载、版本化管理、权限控制、速率限制和审计追踪。本节构建一个完整的ToolRegistry实现，覆盖工具从注册到执行的完整生命周期，实现企业级工具生态管理。

一、工具发现

1.1 注解扫描 — Spring ClassPathScanning

最直接的方案：在Spring Boot应用中通过自定义注解标记工具类，然后通过ClassPathScanning自动发现和注册。

java
import org.springframework.beans.factory.config.BeanDefinition;
import org.springframework.context.annotation.ClassPathScanningCandidateComponentProvider;
import org.springframework.core.type.filter.AnnotationTypeFilter;
import org.springframework.stereotype.Component;

import java.lang.annotation.*;
import java.util.*;

/**
 * 自定义 @Tool 注解，标记工具类。
 */
@Target(ElementType.TYPE)
@Retention(RetentionPolicy.RUNTIME)
@Documented
@Component
public @interface Tool {

    /** 工具唯一名称 */
    String name();

    /** 工具描述 */
    String description();

    /** 工具版本 */
    String version() default "1.0.0";

    /** 工具分类标签 */
    String[] tags() default {};
}

/**
 * 自定义 @ToolMethod 注解，标记工具方法。
 */
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface ToolMethod {

    /** 方法描述 */
    String description();

    /** JSON Schema 文件路径（相对于classpath） */
    String schema() default "";
}

/**
 * 基于注解扫描的工具发现器。
 */
@Component
public class AnnotationToolDiscovery {

    private final ClassPathScanningCandidateComponentProvider scanner;

    public AnnotationToolDiscovery() {
        this.scanner = new ClassPathScanningCandidateComponentProvider(false);
        this.scanner.addIncludeFilter(new AnnotationTypeFilter(Tool.class));
    }

    /**
     * 扫描指定包路径，发现所有 @Tool 标注的类。
     * @return Tool类名与其元数据的映射
     */
    public List<ToolMetadata> discover(String... basePackages) {
        var tools = new ArrayList<ToolMetadata>();

        for (var basePackage : basePackages) {
            for (var beanDef : scanner.findCandidateComponents(basePackage)) {
                try {
                    var clazz = Class.forName(beanDef.getBeanClassName());
                    var toolAnno = clazz.getAnnotation(Tool.class);
                    if (toolAnno == null) continue;

                    var methods = new ArrayList<ToolMethodMetadata>();
                    for (var method : clazz.getDeclaredMethods()) {
                        var methodAnno = method.getAnnotation(ToolMethod.class);
                        if (methodAnno != null) {
                            methods.add(new ToolMethodMetadata(
                                method.getName(),
                                methodAnno.description(),
                                methodAnno.schema(),
                                method.getParameterTypes()
                            ));
                        }
                    }

                    tools.add(new ToolMetadata(
                        toolAnno.name(),
                        toolAnno.description(),
                        toolAnno.version(),
                        Arrays.asList(toolAnno.tags()),
                        clazz,
                        methods
                    ));

                } catch (ClassNotFoundException e) {
                    // 跳过无法加载的类
                }
            }
        }
        return tools;
    }

    public record ToolMetadata(
        String name,
        String description,
        String version,
        List<String> tags,
        Class<?> toolClass,
        List<ToolMethodMetadata> methods
    ) {}

    public record ToolMethodMetadata(
        String methodName,
        String description,
        String schemaPath,
        Class<?>[] parameterTypes
    ) {}
}

1.2 SPI机制 — Java ServiceLoader

对于非Spring环境或需要跨模块扩展的场景，Java SPI（ServiceLoader）是更解耦的方案：

java
/**
 * 工具SPI接口 — 第三方JAR可以通过实现此接口来注册工具。
 */
public interface ToolSpi {

    /** 工具名称 */
    String name();

    /** 工具描述 */
    String description();

    /** JSON Schema for parameters */
    String inputSchema();

    /** 执行工具 */
    ToolResult execute(Map<String, Object> arguments);

    record ToolResult(boolean success, String output, String error) {}
}

/**
 * SPI工具发现器 — 通过META-INF/services加载。
 */
public class SpiToolDiscovery {

    /**
     * 从classpath中发现所有通过SPI注册的工具。
     */
    public List<ToolSpi> discover() {
        var loader = ServiceLoader.load(ToolSpi.class);
        var tools = new ArrayList<ToolSpi>();
        for (var tool : loader) {
            tools.add(tool);
        }
        return tools;
    }
}

// META-INF/services/com.example.tool.ToolSpi 文件内容：
// com.example.tools.DatabaseQueryTool
// com.example.tools.FileSearchTool
// com.example.tools.EmailSendTool

/**

    }

    }

    @Override

            {
              "type": "object",
              "properties": {

                "limit": {"type": "integer", "default": 100}
              },
              "required": ["sql"]
            }

    }

    @Override
    public ToolResult execute(Map<String, Object> arguments) {
        var sql = (String) arguments.get("sql");
        if (sql == null || !sql.trim().toUpperCase().startsWith("SELECT")) {
            return new ToolResult(false, null,
                "Only SELECT queries are allowed");
        }
        // 执行查询...
        return new ToolResult(true, "{\"rows\": [...]}", null);
    }
}

1.3 MCP Tool Listing

MCP协议提供了标准的工具发现和列表化机制。MCP Server通过tools/list方法向Client声明其提供的所有Tool：

java
/**
 * MCP协议工具发现 — Client端获取Server的工具列表。
 */
public class McpToolDiscovery {

    private final McpClient mcpClient;

    public McpToolDiscovery(McpClient mcpClient) {
        this.mcpClient = mcpClient;
    }

    /**
     * 从MCP Server获取工具列表并注册到本地Registry。
     */
    public List<McpToolInfo> discoverAndRegister() {
        // 调用 MCP tools/list 方法
        var tools = mcpClient.listTools();

        return tools.stream()
            .map(tool -> new McpToolInfo(
                tool.name(),
                tool.description(),
                tool.inputSchema(),
                tool.annotations()
            ))
            .toList();
    }

    public record McpToolInfo(
        String name,
        String description,
        JsonNode inputSchema,
        Map<String, Object> annotations
    ) {}
}

二、动态加载

2.1 从JAR包动态加载工具

利用自定义ClassLoader从外部JAR包加载工具类，支持运行时扩展：

java
import java.net.URL;
import java.net.URLClassLoader;
import java.nio.file.Path;
import java.util.ServiceLoader;

/**
 * 从外部JAR包动态加载工具。
 * 支持运行时热加载新的工具包。
 */
public class JarToolLoader implements AutoCloseable {

    private final Map<String, URLClassLoader> classLoaders = new HashMap<>();

    /**
     * 加载JAR包中的SPI工具。
     */
    public List<ToolSpi> loadFromJar(Path jarPath) throws Exception {
        var jarUrl = jarPath.toUri().toURL();
        var classLoader = new URLClassLoader(
            new URL[]{jarUrl},
            Thread.currentThread().getContextClassLoader()
        );

        classLoaders.put(jarPath.getFileName().toString(), classLoader);

        // 使用自定义ClassLoader的ServiceLoader
        var loader = ServiceLoader.load(ToolSpi.class, classLoader);
        var tools = new ArrayList<ToolSpi>();
        for (var tool : loader) {
            tools.add(tool);
        }

        return tools;
    }

    /**
     * 卸载JAR包工具。
     */
    public void unload(String jarFileName) {
        var cl = classLoaders.remove(jarFileName);
        if (cl != null) {
            try {
                cl.close();
            } catch (Exception e) {
                // 记录日志
            }
        }
    }

    @Override
    public void close() {
        classLoaders.forEach((name, cl) -> {
            try { cl.close(); } catch (Exception ignored) {}
        });
    }
}

2.2 从MCP Server远程注册工具

java
import java.util.concurrent.Executors;
import java.util.concurrent.TimeUnit;

/**
 * MCP远程工具注册器。
 * 连接到远程MCP Server，自动获取并注册其提供的所有Tool。
 */
public class McpRemoteToolRegistrar {

    private final ToolRegistry registry;
    private final Map<String, McpClient> mcpClients = new HashMap<>();
    private final ScheduledExecutorService healthChecker =
        Executors.newSingleThreadScheduledExecutor();

    public McpRemoteToolRegistrar(ToolRegistry registry) {
        this.registry = registry;
    }

    /**
     * 连接远程MCP Server并注册其工具。
     */
    public void registerRemoteTools(String serverUrl, String serverName)
            throws Exception {
        var client = McpClient.async(
            new HttpServerTransport(serverUrl)
        ).build();

        client.initialize();
        mcpClients.put(serverName, client);

        // 获取并注册工具
        var tools = client.listTools();
        for (var tool : tools) {
            registry.register(new ToolDefinition(
                serverName + ":" + tool.name(),
                tool.description(),
                tool.inputSchema(),
                ToolSource.remote(serverUrl, serverName),
                "1.0.0",
                List.of()
            ));
        }

        // 周期性健康检查
        healthChecker.scheduleAtFixedRate(() -> {
            try {
                client.ping();
            } catch (Exception e) {
                // 标记所有来自此Server的工具为不可用
                registry.setToolsUnavailable(serverName);
            }
        }, 30, 30, TimeUnit.SECONDS);
    }
}

2.3 热更新工具（不停机）

java
/**
 * 工具热更新管理器。
 * 支持在运行时启用/禁用/替换工具，无需重启应用。
 */
public class HotSwapToolManager {

    private final ToolRegistry registry;
    private final AtomicReference<Map<String, ToolExecutor>> activeExecutors;

    public HotSwapToolManager(ToolRegistry registry) {
        this.registry = registry;
        this.activeExecutors = new AtomicReference<>(new HashMap<>());
    }

    /**
     * 热替换工具：启用新版本后停用旧版本。
     */
    public void hotSwap(String toolName, ToolExecutor newExecutor) {
        var oldExecutors = activeExecutors.get();
        var newExecutors = new HashMap<>(oldExecutors);
        newExecutors.put(toolName, newExecutor);

        // 原子切换
        activeExecutors.set(newExecutors);

        // 延迟关闭旧执行器（等待进行中的请求完成）
        var oldExecutor = oldExecutors.get(toolName);
        if (oldExecutor != null) {
            Thread.ofVirtual().start(() -> {
                try {
                    Thread.sleep(Duration.ofSeconds(30));
                    oldExecutor.close();
                } catch (Exception e) {
                    // 记录日志
                }
            });
        }

        // 通知工具变更事件
        registry.notifyToolChanged(toolName);
    }

    /**
     * 执行工具 — 始终使用最新的Executor。
     */
    public ToolResult execute(String toolName, Map<String, Object> args) {
        var executor = activeExecutors.get().get(toolName);
        if (executor == null) {
            return ToolResult.error("Tool not found: " + toolName);
        }
        return executor.execute(args);
    }
}

三、版本管理

3.1 Semantic Versioning + Changelog

java
/**
 * 工具版本管理器。
 */
public class ToolVersionManager {

    private final Map<String, List<ToolVersionEntry>> versionHistory;

    public ToolVersionManager() {
        this.versionHistory = new ConcurrentHashMap<>();
    }

    public record ToolVersionEntry(
        String toolName,
        SemVer version,
        String changelog,
        String checksum,     // 工具JAR/代码的SHA-256
        Instant createdAt,
        String createdBy
    ) {}

    /**
     * Semantic Versioning解析。
     */
    public record SemVer(int major, int minor, int patch)
            implements Comparable<SemVer> {

        public static SemVer parse(String version) {
            var parts = version.split("\\.");
            if (parts.length < 3) {
                throw new IllegalArgumentException(
                    "Invalid semver: " + version);
            }
            return new SemVer(
                Integer.parseInt(parts[0]),
                Integer.parseInt(parts[1]),
                Integer.parseInt(parts[2])
            );
        }

        @Override
        public int compareTo(SemVer other) {
            int cmp = Integer.compare(major, other.major);
            if (cmp != 0) return cmp;
            cmp = Integer.compare(minor, other.minor);
            if (cmp != 0) return cmp;
            return Integer.compare(patch, other.patch);
        }

        @Override
        public String toString() {
            return STR."\{major}.\{minor}.\{patch}";
        }
    }

    /**
     * 发布新版本。
     */
    public ToolVersionEntry publishVersion(String toolName,
            String newVersion, String changelog, String checksum,
            String createdBy) {
        var semver = SemVer.parse(newVersion);

        // 验证版本递增
        var latest = getLatestVersion(toolName);
        if (latest != null && semver.compareTo(latest.version()) <= 0) {
            throw new IllegalArgumentException(
                STR."Version must be greater than \{latest.version()}");
        }

        var entry = new ToolVersionEntry(
            toolName, semver, changelog, checksum,
            Instant.now(), createdBy
        );

        versionHistory.computeIfAbsent(toolName, k -> new ArrayList<>())
            .add(entry);

        return entry;
    }

    /**
     * 获取某个工具的最新版本。
     */
    public ToolVersionEntry getLatestVersion(String toolName) {
        var history = versionHistory.get(toolName);
        if (history == null || history.isEmpty()) return null;
        return history.getLast();
    }

    /**
     * 获取完整的版本历史。
     */
    public List<ToolVersionEntry> getVersionHistory(String toolName) {
        return versionHistory.getOrDefault(toolName, List.of());
    }
}

3.2 向后兼容策略

java
/**
 * 工具向后兼容策略执行器。
 *
 * 生命周期：
 *   @Deprecated (标记，打印警告) →
 *   宽限期 (指定的N个版本内仍可使用) →
 *   移除 (彻底删除)
 */
public class DeprecationManager {

    private final Map<String, DeprecationInfo> deprecatedTools =
        new ConcurrentHashMap<>();

    public record DeprecationInfo(
        String toolName,
        SemVer deprecatedAtVersion,
        SemVer removalAtVersion,        // 计划移除的版本
        String replacementTool,         // 替代工具名称
        String migrationGuide,          // 迁移指南URL
        Instant deprecatedAt,
        DeprecationStatus status
    ) {}

    public enum DeprecationStatus {
        DEPRECATED,    // 已标记废弃，仍可使用，打印警告
        GRACE_PERIOD,  // 宽限期内，可使用但每次都会提醒
        REMOVED        // 已移除，调用报错
    }

    private final ToolVersionManager.SemVer currentSystemVersion;

    public DeprecationManager(String currentSystemVersion) {
        this.currentSystemVersion =
            ToolVersionManager.SemVer.parse(currentSystemVersion);
    }

    /**
     * 标记工具为废弃。
     */
    public void deprecate(String toolName, String replacementTool,
            String migrationGuide, int graceVersions) {
        var current = currentSystemVersion;
        var removalAt = new ToolVersionManager.SemVer(
            current.major(), current.minor(), 0);

        deprecatedTools.put(toolName, new DeprecationInfo(
            toolName, current, removalAt,
            replacementTool, migrationGuide,
            Instant.now(), DeprecationStatus.DEPRECATED
        ));
    }

    /**
     * 在执行前检查工具是否已被废弃/移除。
     */
    public PreExecutionCheck checkBeforeExecution(String toolName) {
        var info = deprecatedTools.get(toolName);
        if (info == null) {
            return PreExecutionCheck.ALLOWED;
        }

        return switch (info.status()) {
            case DEPRECATED -> PreExecutionCheck.warn(
                STR."Tool '\{toolName}' is deprecated. " +
                STR."Please migrate to '\{info.replacementTool()}'. " +
                STR."See: \{info.migrationGuide()}");
            case GRACE_PERIOD -> PreExecutionCheck.warn(
                STR."Tool '\{toolName}' will be removed in " +
                STR."version \{info.removalAtVersion()}. " +
                "Migrate to '\{info.replacementTool()}'.");
            case REMOVED -> PreExecutionCheck.denied(
                STR."Tool '\{toolName}' has been removed. " +
                STR."Use '\{info.replacementTool()}' instead.");
        };
    }

    public record PreExecutionCheck(
        boolean allowed,
        String message
    ) {
        public static final PreExecutionCheck ALLOWED =
            new PreExecutionCheck(true, null);

        public static PreExecutionCheck warn(String msg) {
            return new PreExecutionCheck(true, msg);
        }

        public static PreExecutionCheck denied(String msg) {
            return new PreExecutionCheck(false, msg);
        }
    }
}

四、权限控制

4.1 RBAC per Tool

java
/**
 * 基于RBAC的工具权限控制。
 */
public class ToolAccessControl {

    private final Map<String, Set<String>> toolRoles =
        new ConcurrentHashMap<>();   // toolName -> allowed roles
    private final Map<String, Set<String>> userRoles =
        new ConcurrentHashMap<>();   // userId -> assigned roles

    /**
     * 为工具配置角色访问权限。
     */
    public void grantToolAccess(String toolName, String... roles) {
        toolRoles.computeIfAbsent(toolName, k -> new HashSet<>())
            .addAll(Arrays.asList(roles));
    }

    /**
     * 为用户分配角色。
     */
    public void assignUserRole(String userId, String... roles) {
        userRoles.computeIfAbsent(userId, k -> new HashSet<>())
            .addAll(Arrays.asList(roles));
    }

    /**
     * 检查用户是否有权限执行指定工具。
     */
    public AccessCheckResult checkAccess(String userId, String toolName) {
        var requiredRoles = toolRoles.get(toolName);
        if (requiredRoles == null || requiredRoles.isEmpty()) {
            // 无角色限制 = 所有用户可访问
            return AccessCheckResult.ALLOWED;
        }

        var userRoleSet = userRoles.getOrDefault(userId, Set.of());
        var hasAccess = requiredRoles.stream()
            .anyMatch(userRoleSet::contains);

        return hasAccess
            ? AccessCheckResult.ALLOWED
            : AccessCheckResult.denied(
                STR."User \{userId} lacks required roles for tool \{toolName}");
    }

    public record AccessCheckResult(boolean allowed, String reason) {
        public static final AccessCheckResult ALLOWED =
            new AccessCheckResult(true, null);

        public static AccessCheckResult denied(String reason) {
            return new AccessCheckResult(false, reason);
        }
    }
}

4.2 参数级权限与审计日志

java
/**
 * 参数级权限 — 敏感参数需要额外审批。
 * 每次工具调用都记录审计日志。
 */
public class SensitiveParamGuard {

    private static final Set<String> SENSITIVE_PARAMS = Set.of(
        "password", "apiKey", "token", "secret",
        "credit_card", "ssn", "phone"
    );

    /**
     * 检查参数中是否包含敏感字段。
     * 如果包含且未经审批，拒绝执行。
     */
    public boolean requiresApproval(Map<String, Object> arguments) {
        return arguments.keySet().stream()
            .anyMatch(k -> SENSITIVE_PARAMS.stream()
                .anyMatch(k.toLowerCase()::contains));
    }

    /**
     * 脱敏处理参数用于审计日志。
     */
    public Map<String, Object> sanitizeForAudit(
            Map<String, Object> arguments) {
        var sanitized = new HashMap<>(arguments);
        sanitized.keySet().removeIf(k ->
            SENSITIVE_PARAMS.stream().anyMatch(k.toLowerCase()::contains));
        // 替换可能包含敏感信息的值为[MASKED]
        sanitized.replaceAll((k, v) ->
            SENSITIVE_PARAMS.stream().anyMatch(k.toLowerCase()::contains)
                ? "[MASKED]" : v);
        return sanitized;
    }
}

五、速率限制

5.1 多维度限流

java
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.TimeUnit;

/**
 * 多维度工具速率限制器。
 * 支持：每工具、每用户、每租户三级限流。
 */
public class ToolRateLimiter {

    private final Map<String, TokenBucket> toolBuckets =
        new ConcurrentHashMap<>();
    private final Map<String, TokenBucket> userBuckets =
        new ConcurrentHashMap<>();
    private final Map<String, TokenBucket> tenantBuckets =
        new ConcurrentHashMap<>();
    private final int maxConcurrent;
    private final Semaphore concurrencyLimiter;

    public ToolRateLimiter(int maxConcurrent) {
        this.maxConcurrent = maxConcurrent;
        this.concurrencyLimiter = new Semaphore(maxConcurrent);
    }

    public void configureToolLimit(String toolName,
            int permitsPerSecond) {
        toolBuckets.put(toolName,
            new TokenBucket(permitsPerSecond));
    }

    public void configureUserLimit(String userId,
            int permitsPerSecond) {
        userBuckets.put(userId,
            new TokenBucket(permitsPerSecond));
    }

    public void configureTenantLimit(String tenantId,
            int permitsPerSecond) {
        tenantBuckets.put(tenantId,
            new TokenBucket(permitsPerSecond));
    }

    /**
     * 尝试获取执行许可。
     */
    public RateLimitResult tryAcquire(String toolName, String userId,
            String tenantId) {
        // 1. 并发控制
        if (!concurrencyLimiter.tryAcquire()) {
            return RateLimitResult.denied(
                "Concurrency limit reached");
        }

        // 2. 工具级限流
        var toolBucket = toolBuckets.get(toolName);
        if (toolBucket != null && !toolBucket.tryConsume()) {
            concurrencyLimiter.release();
            return RateLimitResult.denied(
                STR."Tool '\{toolName}' rate limit exceeded");
        }

        // 3. 用户级限流
        var userBucket = userBuckets.get(userId);
        if (userBucket != null && !userBucket.tryConsume()) {
            if (toolBucket != null) toolBucket.refund();
            concurrencyLimiter.release();
            return RateLimitResult.denied("User rate limit exceeded");
        }

        // 4. 租户级限流
        var tenantBucket = tenantBuckets.get(tenantId);
        if (tenantBucket != null && !tenantBucket.tryConsume()) {
            if (toolBucket != null) toolBucket.refund();
            if (userBucket != null) userBucket.refund();
            concurrencyLimiter.release();
            return RateLimitResult.denied(
                "Tenant rate limit exceeded");
        }

        return RateLimitResult.allowed(() -> {
            concurrencyLimiter.release();
        });
    }

    public record RateLimitResult(
        boolean allowed,
        String reason,
        Runnable onComplete
    ) {
        public static RateLimitResult allowed(Runnable release) {
            return new RateLimitResult(true, null, release);
        }
        public static RateLimitResult denied(String reason) {
            return new RateLimitResult(false, reason, () -> {});
        }
    }

    /**
     * JDK令牌桶实现。
     */
    static class TokenBucket {
        final double rate;
        final double maxTokens;
        double tokens;
        volatile long lastRefill;

        TokenBucket(double tokensPerSecond) {
            this.rate = tokensPerSecond;
            this.maxTokens = tokensPerSecond;
            this.tokens = tokensPerSecond;
            this.lastRefill = System.nanoTime();
        }

        synchronized boolean tryConsume() {
            refill();
            if (tokens >= 1.0) {
                tokens -= 1.0;
                return true;
            }
            return false;
        }

        synchronized void refund() {
            tokens = Math.min(maxTokens, tokens + 1.0);
        }

        private void refill() {
            var now = System.nanoTime();
            var elapsed = (now - lastRefill) / 1_000_000_000.0;
            tokens = Math.min(maxTokens, tokens + elapsed * rate);
            lastRefill = now;
        }
    }
}

/**
 * 工具执行排队管理器。
 * 当工具并发达到上限时，新请求进入等待队列。
 */
public class ToolExecutionQueue {

    private final Map<String, LinkedBlockingQueue<QueuedRequest>> queues;
    private final int maxQueueSize;
    private final Duration defaultTimeout;

    public ToolExecutionQueue(int maxQueueSize, Duration defaultTimeout) {
        this.queues = new ConcurrentHashMap<>();
        this.maxQueueSize = maxQueueSize;
        this.defaultTimeout = defaultTimeout;
    }

    public record QueuedRequest(
        String requestId,
        Map<String, Object> arguments,
        CompletableFuture<ToolResult> resultFuture,
        Instant enqueuedAt
    ) {}

    /**
     * 提交请求到队列。如果队列已满则立即拒绝。
     */
    public CompletableFuture<ToolResult> submit(String toolName,
            Map<String, Object> args) {
        var future = new CompletableFuture<ToolResult>();

        var queue = queues.computeIfAbsent(toolName,
            k -> new LinkedBlockingQueue<>(maxQueueSize));

        var request = new QueuedRequest(
            UUID.randomUUID().toString(), args, future, Instant.now());

        if (!queue.offer(request)) {
            future.complete(ToolResult.error(
                STR."Queue full for tool '\{toolName}'."));
            return future;
        }

        return future.orTimeout(defaultTimeout.toMillis(),
            TimeUnit.MILLISECONDS);
    }

    /**
     * 从队列中取出下一个请求。
     */
    public Optional<QueuedRequest> poll(String toolName,
            Duration waitTime) {
        var queue = queues.get(toolName);
        if (queue == null) return Optional.empty();

        try {
            return Optional.ofNullable(
                queue.poll(waitTime.toMillis(), TimeUnit.MILLISECONDS));
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            return Optional.empty();
        }
    }
}

将以上所有能力整合为一个企业级ToolRegistry：

java
/**
 * 企业级ToolRegistry — 整合注册/发现/鉴权/限流/版本/审计全链路。
 */
@Service
public class ToolRegistry {

    // 工具注册表：存储所有已注册的工具定义
    private final Map<String, ToolRegistration> registrations =
        new ConcurrentHashMap<>();

    // 子组件
    private final AnnotationToolDiscovery annotationDiscovery;
    private final SpiToolDiscovery spiDiscovery;
    private final ToolAccessControl accessControl;
    private final ToolRateLimiter rateLimiter;
    private final ToolVersionManager versionManager;
    private final DeprecationManager deprecationManager;
    private final ToolAuditLogger auditLogger;
    private final SensitiveParamGuard paramGuard;
    private final ToolExecutionQueue executionQueue;

    public ToolRegistry() {
        this.annotationDiscovery = new AnnotationToolDiscovery();
        this.spiDiscovery = new SpiToolDiscovery();
        this.accessControl = new ToolAccessControl();
        this.rateLimiter = new ToolRateLimiter(100);
        this.versionManager = new ToolVersionManager();
        this.deprecationManager = new DeprecationManager("2.0.0");
        this.auditLogger = new ToolAuditLogger();
        this.paramGuard = new SensitiveParamGuard();
        this.executionQueue = new ToolExecutionQueue(50,
            Duration.ofSeconds(60));
    }

    /**
     * 工具注册信息。
     */
    public record ToolRegistration(
        ToolDefinition definition,
        ToolExecutor executor,
        ToolSource source
    ) {}

    // ===== 注册 =====

    /**
     * 注册工具。
     */
    public void register(ToolDefinition definition, ToolExecutor executor,
            ToolSource source) {
        registrations.put(definition.name(),
            new ToolRegistration(definition, executor, source));
    }

    /**
     * 启动时自动发现并注册所有工具。
     * 扫描顺序：注解扫描 → SPI → MCP远程注册。
     */
    public void bootstrap(String... basePackages) {
        // 1. 注解扫描
        var annotatedTools = annotationDiscovery.discover(basePackages);
        for (var tool : annotatedTools) {
            var executor = createAnnotatedExecutor(tool);
            register(new ToolDefinition(tool.name(), tool.description(),
                "{}", ToolSource.local(tool.toolClass().getName()),
                tool.version(), tool.tags()), executor,
                ToolSource.local(tool.toolClass().getName()));
        }

        // 2. SPI发现
        var spiTools = spiDiscovery.discover();
        for (var tool : spiTools) {
            register(new ToolDefinition(tool.name(), tool.description(),
                tool.inputSchema(),
                ToolSource.local(tool.getClass().getName()),
                "1.0.0", List.of()),
                tool::execute,
                ToolSource.local(tool.getClass().getName()));
        }
    }

    // ===== 执行全链路 =====

    /**
     * 执行工具 — 通过完整的权限/限流/审计链路。
     */
    public ToolResult executeSecurely(String toolName,
            Map<String, Object> arguments,
            ExecutionContext context) {
        var callId = UUID.randomUUID().toString();
        var startTime = System.currentTimeMillis();

        // Phase 1: 注册检查
        var reg = registrations.get(toolName);
        if (reg == null) {
            return ToolResult.error("Tool not found: " + toolName);
        }

        // Phase 2: 废弃检查
        var deprecationCheck =
            deprecationManager.checkBeforeExecution(toolName);
        if (!deprecationCheck.allowed()) {
            return ToolResult.error(deprecationCheck.message());
        }
        if (deprecationCheck.message() != null) {
            logger.warn(deprecationCheck.message());
        }

        // Phase 3: 权限检查
        var accessCheck = accessControl.checkAccess(
            context.userId(), toolName);
        if (!accessCheck.allowed()) {
            auditLogger.log(callId, toolName, context.userId(),
                context.tenantId(), arguments, null,
                System.currentTimeMillis() - startTime,
                context.traceId());
            return ToolResult.error(accessCheck.reason());
        }

        // Phase 4: 敏感参数检查
        if (paramGuard.requiresApproval(arguments) &&
                !context.humanApproved()) {
            return ToolResult.error(
                "Tool requires human approval for sensitive parameters");
        }

        // Phase 5: 速率限制
        var rateCheck = rateLimiter.tryAcquire(
            toolName, context.userId(), context.tenantId());
        if (!rateCheck.allowed()) {
            return ToolResult.error(rateCheck.reason());
        }

        // Phase 6: Schema校验
        var schemaValidation = validateSchema(
            reg.definition().inputSchema(), arguments);
        if (!schemaValidation.valid()) {
            rateCheck.onComplete().run();
            return ToolResult.error(
                "Schema validation failed: " + schemaValidation.errors());
        }

        // Phase 7: 执行
        ToolResult result;
        try {
            result = reg.executor().execute(arguments);
        } catch (Exception e) {
            result = ToolResult.error(
                "Execution error: " + e.getMessage());
        }

        // Phase 8: 审计
        rateCheck.onComplete().run();
        auditLogger.log(callId, toolName, context.userId(),
            context.tenantId(),
            paramGuard.sanitizeForAudit(arguments),
            result,
            System.currentTimeMillis() - startTime,
            context.traceId());

        return result;
    }

    /**
     * 列出所有工具（用于Agent Tool Discovery）。
     */
    public List<ToolDefinition> listTools(String userId) {
        return registrations.values().stream()
            .filter(reg -> accessControl.checkAccess(
                userId, reg.definition().name()).allowed())
            .map(ToolRegistration::definition)
            .toList();
    }

    /**
     * 通知工具变更事件。
     */
    public void notifyToolChanged(String toolName) {
        // 可通过Spring Event或Kafka广播工具变更
        eventPublisher.publish(
            new ToolChangedEvent(toolName, Instant.now()));
    }

    public void setToolsUnavailable(String serverName) {
        registrations.entrySet().stream()
            .filter(e -> e.getValue().source().serverName() != null
                && e.getValue().source().serverName().equals(serverName))
            .forEach(e -> e.getValue().definition().setAvailable(false));
    }
}

七、最佳实践

  1. 默认拒绝：权限策略默认为deny-all，需要显式授权
  2. 分层限流：同时配置全局限流（保护系统）和用户级限流（保护公平性）
  3. 版本化Schema：Tool的JSON Schema格式变更时需递增版本号，支持多版本并存
  4. 审计不可删除：审计日志应写入不可变存储（如Kafka + 冷存储），至少保留90天
  5. 降级策略：当MCP远程工具不可用时，应明确告知Agent而非静默失败

八、常见问题

Q: 如何避免工具注册重复？ A: 使用工具名称作为唯一键，后注册的覆盖先注册的。启动时按优先级加载：本地注解工具 > SPI工具 > MCP远程工具。

Q: 工具版本兼容性如何自动化验证？ A: 在CI中运行工具的Input/Output契约测试。每当Schema变更时，验证新版本与旧版本客户端调用的兼容性。

Q: 工具的执行超时如何设定？ A: 默认30秒硬超时。对于数据查询类工具可放宽到120秒，对于实时计算类工具收紧到10秒。超时时间记录在ToolDefinition中。
