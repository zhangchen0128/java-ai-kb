# Model Capability and Routing

## 概述

截至 2026 年 7 月，LLM 市场已经从"一家独大"走向"百花齐放"。不同的模型在推理、代码、多语言、多模态、成本等维度各有优劣。选对模型可以显著降低成本同时保持甚至提升质量。本文提供模型能力矩阵、选型决策树和模型路由的工程实现。

## 模型路由策略

### 1. 能力路由（Capability-based Routing）

按任务类型自动分发到最合适的模型。

```java
import java.util.*;
import java.util.function.Predicate;

/**
 * 能力路由：根据任务类型选择模型
 */
public class CapabilityBasedRouter {

    public enum TaskType {
        CODE_GENERATION("代码生成/审查"),
        DOCUMENT_ANALYSIS("长文档分析"),
        CHINESE_TASK("中文为主任务"),
        SIMPLE_EXTRACTION("简单提取/分类"),
        TOOL_CALLING("工具调用/Agent"),
        CREATIVE_WRITING("创意写作"),
        GENERAL("通用对话");

        private final String description;
        TaskType(String desc) { this.description = desc; }
    }

    public record RouteConfig(
        String modelId,
        String provider,
        TaskType taskType,
        int priority  // 同类型有多个候选时按优先级
    ) {}

    /**
     * 模型路由表
     */
    public static final Map<TaskType, List<RouteConfig>> ROUTING_TABLE = Map.of(
        TaskType.CODE_GENERATION, List.of(
            new RouteConfig("claude-sonnet-4-20250514", "anthropic", TaskType.CODE_GENERATION, 1),
            new RouteConfig("claude-opus-4-20250514", "anthropic", TaskType.CODE_GENERATION, 2),
            new RouteConfig("gpt-5", "openai", TaskType.CODE_GENERATION, 3)
        ),
        TaskType.CHINESE_TASK, List.of(
            new RouteConfig("deepseek-v3", "deepseek", TaskType.CHINESE_TASK, 1),
            new RouteConfig("qwen3-235b", "self-hosted", TaskType.CHINESE_TASK, 2),
            new RouteConfig("gpt-5", "openai", TaskType.CHINESE_TASK, 3)
        ),
        TaskType.SIMPLE_EXTRACTION, List.of(
            new RouteConfig("claude-haiku-4-5", "anthropic", TaskType.SIMPLE_EXTRACTION, 1),
            new RouteConfig("gpt-5-mini", "openai", TaskType.SIMPLE_EXTRACTION, 2),
            new RouteConfig("gemini-3-flash", "google", TaskType.SIMPLE_EXTRACTION, 3)
        ),
        TaskType.GENERAL, List.of(
            new RouteConfig("claude-sonnet-4-20250514", "anthropic", TaskType.GENERAL, 1)
        )
    );

    /**
     * 根据任务类型路由
     */
    public RouteConfig route(TaskType taskType) {
        var candidates = ROUTING_TABLE.getOrDefault(taskType,
            ROUTING_TABLE.get(TaskType.GENERAL));

        return candidates.stream()
            .min(Comparator.comparingInt(RouteConfig::priority))
            .orElseThrow(() -> new IllegalStateException(
                "No route for task type: " + taskType));
    }
}
```

### 2. 成本路由（Cost-based Routing）

在预算范围内自动选择最优模型。

```java
/**
 * 成本路由：在预算约束下选择最优模型
 */
public class CostBasedRouter {

    public record ModelInfo(
        String modelId,
        double inputPricePer1M,
        double outputPricePer1M,
        double qualityScore,     // 1-10 质量评级
        int contextWindow,
        boolean available         // 当前是否可用
    ) {
        /**
         * 性价比 = 质量 / 成本
         */
        public double qualityCostRatio(int estimatedTokens) {
            double estimatedCost = (estimatedTokens / 1_000_000.0) *
                (inputPricePer1M + outputPricePer1M) / 2;
            return qualityScore / Math.max(estimatedCost, 0.0001);
        }
    }

    private final List<ModelInfo> models = List.of(
        new ModelInfo("claude-opus-4-20250514", 15.0, 75.0, 9.5, 200_000, true),
        new ModelInfo("claude-sonnet-4-20250514", 3.0, 15.0, 9.0, 200_000, true),
        new ModelInfo("claude-haiku-4-5", 0.8, 4.0, 8.0, 200_000, true),
        new ModelInfo("gpt-5", 12.5, 50.0, 9.3, 128_000, true),
        new ModelInfo("gpt-5-mini", 0.75, 3.0, 8.2, 128_000, true),
        new ModelInfo("deepseek-v3", 0.27, 1.10, 8.5, 128_000, true),
        new ModelInfo("qwen3-32b-self-host", 0, 0, 7.5, 128_000, true)
    );

    /**
     * 在预算内选性价比最高的模型
     * @param estimatedTokens 预估总 token 数
     * @param maxBudget 最大预算（美元）
     * @param minQuality 最低质量要求
     */
    public Optional<ModelInfo> selectBestWithinBudget(
            int estimatedTokens, double maxBudget, double minQuality) {

        return models.stream()
            .filter(ModelInfo::available)
            .filter(m -> m.qualityScore() >= minQuality)
            .filter(m -> {
                double cost = estimatedTokens / 1_000_000.0 *
                    (m.inputPricePer1M() + m.outputPricePer1M()) / 2;
                return cost <= maxBudget;
            })
            .max(Comparator.comparingDouble(m ->
                m.qualityCostRatio(estimatedTokens)));
    }

    /**
     * 获取当前最便宜的可用模型
     */
    public ModelInfo getCheapest() {
        return models.stream()
            .filter(ModelInfo::available)
            .min(Comparator.comparingDouble(
                m -> m.inputPricePer1M() + m.outputPricePer1M()))
            .orElseThrow();
    }
}
```

### 3. 故障转移路由（Fallback Routing）

主模型不可用时自动切换到备用模型。

```java
import java.time.Instant;
import java.time.Duration;

/**
 * 故障转移路由器
 */
public class FallbackRouter {

    public record ModelEndpoint(
        String modelId,
        String provider,
        String apiKey,
        int priority,             // 1=首选, 2=备用, 3=兜底
        boolean healthy,
        int consecutiveFailures,
        Instant lastFailureTime
    ) {}

    private final List<ModelEndpoint> endpoints;
    private static final int FAILURE_THRESHOLD = 3;
    private static final Duration COOLDOWN_DURATION = Duration.ofMinutes(5);

    public FallbackRouter(List<ModelEndpoint> endpoints) {
        this.endpoints = new ArrayList<>(endpoints);
        this.endpoints.sort(Comparator.comparingInt(ModelEndpoint::priority));
    }

    /**
     * 按优先级依次尝试，直到有一个成功
     */
    public String executeWithFallback(
            java.util.function.Function<ModelEndpoint, String> apiCall) {

        List<String> errors = new ArrayList<>();

        for (var endpoint : endpoints) {
            // 跳过不健康的端点
            if (!endpoint.healthy()) {
                errors.add(endpoint.modelId() + ": unhealthy (skipped)");
                continue;
            }
            // 跳过低优先级的本地模型（在非必要情况下不使用）
            if (endpoint.priority() > 2) {
                errors.add(endpoint.modelId() + ": low priority, trying main");
                continue;
            }

            try {
                var result = apiCall.apply(endpoint);
                // 成功后重置失败计数
                resetFailureCount(endpoint);
                return result;
            } catch (Exception e) {
                recordFailure(endpoint);
                errors.add(endpoint.modelId() + ": " + e.getMessage());
            }
        }

        // 全部失败，尝试低优先级本地模型作为最后兜底
        for (var endpoint : endpoints) {
            if (endpoint.priority() <= 2) continue;  // 已经尝试过
            try {
                var result = apiCall.apply(endpoint);
                resetFailureCount(endpoint);
                return result;
            } catch (Exception e) {
                recordFailure(endpoint);
                errors.add(endpoint.modelId() + ": " + e.getMessage());
            }
        }

        throw new RuntimeException("所有模型端点均失败:\n" +
            String.join("\n", errors));
    }
```

### 4. 灰度发布路由

将新技术模型逐步放量。

```java
import java.security.MessageDigest;
import java.util.concurrent.atomic.AtomicInteger;
import java.util.concurrent.atomic.AtomicLong;

/**
 * 灰度发布路由器
 * 支持按比例将流量分流到新模型
 */
public class CanaryRouter {

    public record CanaryConfig(
        String stableModelId,      // 稳定模型（主线）
        String canaryModelId,      // 金丝雀模型（灰度）
        int canaryPercentage,      // 灰度流量百分比 (0-100)
        Instant startedAt,         // 灰度开始时间
        EvaluationCriteria criteria // 评估标准
    ) {}

    public record EvaluationCriteria(
        double minQualityThreshold,
        double maxLatencyMs,
        double maxCostPerRequest
    ) {}

    private CanaryConfig config;
    private final AtomicLong canaryRequests = new AtomicLong(0);
    private final AtomicInteger canaryErrors = new AtomicInteger(0);

    /**
     * 判断当前请求是否走灰度
     */
    public String selectModel(String requestId) {
        if (config == null) {
            return config.stableModelId();
        }

        // 用请求 ID 做确定性哈希，保证同一请求稳定
        int hash = Math.abs(requestId.hashCode()) % 100;

        if (hash < config.canaryPercentage()) {
            canaryRequests.incrementAndGet();
            return config.canaryModelId();
        }

        return config.stableModelId();
    }

    /**
     * 记录灰度模型的结果
     */
    public void recordCanaryResult(String requestId, boolean success,
            long latencyMs, double cost) {
        if (!success) {
            canaryErrors.incrementAndGet();
        }
    }

    /**
     * 评估灰度是否应该全量
     */
    public boolean shouldPromoteToFull() {
        long total = canaryRequests.get();
        if (total < 1000) return false;  // 样本太少

        double errorRate = (double) canaryErrors.get() / total;
        return errorRate < 0.01;  // 错误率 < 1% → 全量
    }

    /**
     * 评估灰度是否应该回滚
     */
    public boolean shouldRollback() {
        long total = canaryRequests.get();
        if (total < 100) return false;

        double errorRate = (double) canaryErrors.get() / total;
        return errorRate > 0.05;  // 错误率 > 5% → 回滚
    }
}
```

### 5. Spring AI 实现示例

```java
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.stereotype.Component;

/**
 * Spring AI 环境下的模型路由实现
 */
@Component
public class SpringAiModelRouter {

    private final ChatClient.Builder chatClientBuilder;

    public record RouterDecision(
        String chatModelBeanName,
        double temperature,
        int maxTokens,
        String reason
    ) {}

    public SpringAiModelRouter(ChatClient.Builder chatClientBuilder) {
        this.chatClientBuilder = chatClientBuilder;
    }

    /**
     * 根据请求内容智能路由
     */
    public RouterDecision decide(String userMessage) {
        // 简单任务的信号
        if (isSimpleClassification(userMessage)) {
            return new RouterDecision(
                "haikuChatModel",     // bean name
                0.0,                   // 零温度确保确定性
                100,
                "简单分类任务 → Haiku");
        }

        // 代码生成
        if (isCodeGeneration(userMessage)) {
            return new RouterDecision(
                "claudeSonnetChatModel",
                0.2,
                4096,
                "代码生成 → Claude Sonnet");
        }

        // 中文任务
        if (isChineseTask(userMessage)) {
            return new RouterDecision(
                "deepseekChatModel",
                0.7,
                2048,
                "中文任务 → DeepSeek V3 (高性价比)");
        }

        // 默认
        return new RouterDecision(
            "claudeSonnetChatModel",
            0.7,
            2048,
            "通用任务 → Claude Sonnet");
    }

    /**
     * 使用路由决策发起调用
     */
    public String routeAndCall(String userMessage) {
        var decision = decide(userMessage);
        System.out.println("路由决策: " + decision.reason());

        // 从 ApplicationContext 获取对应 Bean
        // 在实际 Spring 应用中通过 ApplicationContext.getBean()
        // ChatModel chatModel = context.getBean(decision.chatModelBeanName(),
        //     ChatModel.class);
        // ChatClient client = ChatClient.builder(chatModel).build();

        // 伪代码（实际需注入 ApplicationContext）
        return "Response from " + decision.chatModelBeanName() +
            " (温度=" + decision.temperature() + ")";
    }

    private boolean isSimpleClassification(String message) {
        return message.length() < 100 &&
            (message.contains("分类") || message.contains("提取") ||
             message.contains("判断") || message.contains("是否"));
    }

    private boolean isCodeGeneration(String message) {
        return message.contains("代码") || message.contains("code") ||
            message.contains("写一个") || message.contains("实现") ||
            message.contains("函数") || message.contains("class");
    }

    private boolean isChineseTask(String message) {
        int chineseChars = 0;
        int totalChars = message.length();
        for (char c : message.toCharArray()) {
            if (Character.UnicodeScript.of(c) ==
                    Character.UnicodeScript.HAN) chineseChars++;
        }
        return (double) chineseChars / totalChars > 0.5;
    }
}
```

```
│  2. 模型选择 (Model Selection)                           │
│     ├── 能力匹配：筛选支持该任务类型的模型                  │
│     ├── 成本过滤：滤除超出预算的模型                       │
│     ├── 健康检查：滤除不可用的模型                         │
│     └── 灰度规则：检查是否命中金丝雀                       │
│                                                          │
│  3. 执行调用                                             │
│     ├── 尝试首选模型                                      │
│     ├── 失败？→ 尝试备用模型                               │
│     └── 全部失败？→ 尝试本地兜底模型                       │
│                                                          │
│  4. 结果记录                                             │
│     ├── 延迟、成本、成功率                                │
│     └── 反馈到路由决策（在线学习）                         │
└──────────────────────────────────────────────────────────┘
```

## 最佳实践

1. **默认模型选择**：Claude Sonnet 4.5 是当前质量/速度/成本的最佳平衡点，适合作为默认模型
2. **中文场景**：如果项目大量使用中文，DeepSeek-V3 是性价比之王——质量接近 GPT-5，成本只有 1/20
3. **简单任务不要用大模型**：情感分析、NER、文本分类等任务，Haiku 4.5 和 GPT-5 Mini 的质量与大模型几乎无差异，但成本差 10 倍以上
4. **工具调用用 Claude**：Claude 系列（特别是 Sonnet 4.5）在 Tool Calling 准确性和一致性上公认最强
5. **长文档理解用 Claude**：200K 原生上下文窗口 + 极高召回率，是长文档任务的不二之选
6. **灰度发布新模型时务必设立明确的回滚标准**：错误率 > 5% 或 P95 延迟 > 2x → 立即回滚
7. **本地自托管模型最好作为兜底而非主力**：质量有差距，但可以保证服务可用性

## 常见问题

**Q: 什么时候应该用 Claude Opus 4.8 而不是 Sonnet 4.5？**

A: 当任务难度足够高时——复杂多步推理、高难度代码架构设计、需要"深思熟虑"的法律/金融分析。对日常任务，Sonnet 4.5 的质量已足够，Opus 的额外成本不值得。

**Q: 国产模型（Qwen/DeepSeek）能替代 GPT/Claude 吗？**

A: 对于中文为主、代码辅助、通用问答场景，完全可以。但对于需要极高推理精度或 Tool Calling 准确性的场景，闭源模型仍有优势。建议中文场景用国产模型主力，复杂推理补充用闭源模型。

**Q: 模型路由的 overhead 是多少？**

A: 任务分类的开销。通常使用简单的规则（关键词匹配 + 百分比规则）+ 一个超轻量分类器（~10ms）。如果使用 LLM 做分类，增加约 0.5-1s 延迟但结果更准。推荐：先上规则，规则无法覆盖的再用 LLM 分类。
